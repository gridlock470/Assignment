# Question 1. 
HTTP Request–Response Cycle

The HTTP Request–Response Cycle is the process through which a client, communicates with a server to request and receive resources.

### Major steps Included
1. Enter a URL
2. Request is identified by server
3. Connection is established by server
4. Client sends a request
5. Server requests the process
6. Server rends a response
7. The result is displayed

# Question 8.
There are 3 types of CSS
1. Inline CSS
2. Internal CSS
3. External CSS

## Inline CSS
**Inline CSS** is written directly inside an HTML file.

Characteristics
1. Applied to a single element.
2. Useable for small and non - detailed styling.
3. Not suggested as this is not helpful in maintaining code.

## Internal CSS
internal CSS is written in the HTML file itself, usually in side head section.

Characteristics
1. CSS is written in same file.
2. Can style multiple elements.
3. Useful for single web page.

## External CSS
External CSS is written in a separate file with .css extension and then is linked to HTML document.

Characteristics
1. CSS is stored in a separate file.
2. Only one CSS file is required.
3. This one file can style multiple webpages.
4. Best suited for large projects.
